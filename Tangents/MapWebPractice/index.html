📖 Follow the tutorial

  1. The map <div id="map"> and Leaflet CSS/JS are already wired up below.
  2. Scroll to the <script> block at the bottom of this file and replace the starter code with each tutorial snippet as you go.
  3. Use L.map('map') to initialise, L.tileLayer(...) to add tiles, then experiment with markers, circles, and popups.
  4. Save and refresh your browser — no build step needed.
