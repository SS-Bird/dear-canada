I want to set up a basic website to host an interactive map representing the history of Canada and its representation in the Dear Canada series, and related matierals. 

For now, this will not be user oriented, but I want to leave room for it to evolve into that later. Right now it will be a place to explore and share the meta data I am creating. 

Details for organisation and design can be found on DESIGN.md.

I plan to deploy on vercel. 

I don't want to constantly reuploading the data everytime I open the website, but also it will need to be changed out frequently. I am willing to be flexible about this if permenantly storing the data on the site will create issues to changing it.
